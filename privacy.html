Privacy Policy — hermes-oauth

Last updated: 3 November 2026

1. Scope

This privacy policy covers hermes-oauth ("the Application"), a personal, single-user OAuth client used by its owner's self-hosted AI assistant to access the owner's own Google account data.

2. What data the Application accesses

With the owner's explicit consent, the Application may access:

  • Gmail — the owner's email messages (read, search, and the ability to create drafts or send mail on the owner's instruction).
  • Google Calendar — the owner's calendar events and schedules.

The Application accesses only the Google account of the single person who authorized it. It has no access to any other user's data.

3. How the data is used

Data is used for one purpose only: to generate a private, personal summary (for example a daily briefing of the owner's own email and calendar) and to carry out tasks the owner explicitly requests of their own assistant.

4. Where the data is stored

All data and OAuth credentials are stored locally on the owner's own computer. OAuth refresh tokens are stored in a local file readable only by the owner's operating-system account.

No data is transmitted to, stored on, or processed by any server operated by the author of this Application. There is no analytics, no telemetry, and no advertising.

5. Sharing with third parties

The Application does not sell, rent, share, or disclose Google user data to any third party. Google user data is never used for advertising, and never used to train generalized AI/ML models.

6. Google API Services User Data Policy

The Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Data retention and deletion

The owner may revoke the Application's access at any time from the Google account permissions page (myaccount.google.com/permissions). Revoking access immediately invalidates the stored token. Locally cached data can be deleted at any time by the owner by removing the Application's local data files.
