hermes-oauth

hermes-oauth is a personal, single-user OAuth application. It is used by the owner's own self-hosted AI assistant (Hermes Agent, running on the owner's private computer) to access the owner's own Gmail messages and Google Calendar events.

What this application does

  • Reads the owner's own unread email and upcoming calendar events in order to produce a private, personal daily summary for that same owner.
  • Runs entirely on the owner's own computer. There is no server hosted by anyone else, and no other person has access to the data.
  • It is single-user: it is not distributed, not offered to the public, and not used commercially.
  • It does not post, publish, or send the owner's data to third parties.

Who uses it

One person only — the owner of the Google account that authorizes it.

Data handling

This application accesses only the owner's own Google account data, and only for the single-user purpose described above. See the Privacy Policy for full details.
